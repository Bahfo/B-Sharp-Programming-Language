# Utilities

This folder contains all utilities that come pre-installed with B-Sharp Programming Language.

What to expect: 

- `run.d`: Contains the source code for running a .bsharp file. Simply: `bsharp run file.bsharp`
- `scan.d`: Contains the source code for scanning a directory for special `.bsharp` files, these files are `__init__.bsharp` and other standard libraries written in other programming languages.
- `test.d`: Contains codes for tests.
