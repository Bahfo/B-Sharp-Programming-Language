B-Sharp is a general-purpose language designed to be simple to use, portable, and controllable as much as a user wishes it to be. B-Sharp is also robust and optionally-typed by its nature.

B-Sharp offers you clean syntax, it also comes with multiple declarations for the same job.

fn add_two_numbers(x, y) { return x + y; } function add_two_numbers_remastered(x, y) { return x + y; }

B-Sharp follows your commands precisely, tell it to enforce typing and it does at greatest checking.

var x : Number = 5; var y : String = "Hello, Programmer!";

B-Sharp is interpreted and compiled. Try it!

bsharp build my_file.bsharp bsharp run my_file.bsharp

Don't forget to call foreign languages inside your B-Sharp code as well.

__inline__(x, y) CPlusPlus { int multiply(int x, int y) { return x * y; } int result = multiply(5, 6); } expect(result)

Strong features that make the language not only make the language rich, but helpful at needs.
