## Grammar Keywords in B-Sharp

The following table includes the list of all keywords in B-Sharp programming language.

| Keyword | Usage |
| --- | --- |
| `or` | Logical operator |
| `if` | Conditional operator |
| `fn` | Function definition |
| `var` | Variable declaration |
| `for` | Loop operator |
| `and` | Logical operator |
| `not` | Logical operator |
| `else` | Conditional operator |
| `elif` | Conditional operator |
| `then` | Conditional and Loop operator |
| `none` | Value |
| `true` | Value |
| `false` | Value |
| `const` | Constant declaration |
| `while` | Logical operator |
| `Empty` | Type definition |
| `Number` | Type definition |
| `String` | Type definition |
| `Boolean` | Type definition |
| `using` | Module import |
